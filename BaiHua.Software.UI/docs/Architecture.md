# BaiHua.Software 上位机通用框架 - 架构设计文档

## 📋 项目概述

BaiHua.Software 是一个**上位机（SCADA/HMI）通用框架**，基于 .NET 8 构建，采用**分层架构 + 模块化设计**，为工业自动化应用提供完整的业务支撑。

**技术栈**：
- 框架：.NET 8
- UI框架：WPF + **Prism 9.0** (模块化 MVVM)
- 依赖注入：Prism.DryIOC
- 主机框架：Microsoft.Extensions.Hosting
- **模块系统**：自定义模块化框架 + Prism

---

## 📦 核心模块详解

### 1️⃣ **Common (01 BaiHua.Software.Common)** - 公共工具层

**职责**：提供全局通用的帮助类和工具函数

**主要功能**：
- JSON 序列化与反序列化（基于 Newtonsoft.Json）
- 加密解密功能
- 文件读写操作
- 字符串扩展方法
- 集合操作扩展
- 日期时间处理工具

**特点**：
- ✅ 高度独立，无外部业务依赖
- ✅ 可被所有其他层安全引用
- ✅ 提供可复用的通用算法

---

### 2️⃣ **Core (02 BaiHua.Software.Core)** - 核心契约层

**职责**：定义系统的基础契约，是整个框架的基石

**主要功能**：
- **Interfaces**：所有业务接口的抽象定义
- **Enums**：全局枚举定义（状态、类型等）
- **DTO**：数据传输对象（Data Transfer Objects）
- **Domain Models**：领域模型定义

**设计原则**：
- 🔒 **最底层的契约**：不依赖任何外部包或具体实现
- 🔒 **所有层安全引用**：其他层都可以安全地引用此层
- 🔒 **无外部依赖**：确保核心层的稳定性

**示例**：
```csharp
// Core 层定义的接口
public interface IDeviceService { }
public interface IAlarmService { }

// Core 层定义的枚举
public enum WorkstationStatus { Idle, Running, Error }

// Core 层定义的 DTO
public class ProductDTO { }
```

---

### 3️⃣ **Infrastructure (03 BaiHua.Software.Infrastructure)** - 基础设施层

**职责**：提供系统基础服务能力的实现

**主要依赖**：
- 📊 **FreeSql**：ORM 框架，提供数据库访问仓储实现
- 📝 **Serilog**：日志框架，提供日志记录实现

**主要功能**：
- 数据库连接与操作（增删改查）
- 仓储模式实现（Repository Pattern）
- 日志记录与管理
- 事务处理
- 数据缓存

**特点**：
- ✅ 统一的数据访问接口
- ✅ 结构化日志记录
- ✅ 支持多数据库切换

---

### 4️⃣ **HAL (02 BaiHua.Software.HAL)** - 硬件抽象层

**职责**：封装具体硬件设备的驱动实现

**主要功能**：

#### 📷 **视觉模块**
- 基于 OpenCvSharp4 的视觉算法封装
- 图像处理：缩放、旋转、模板匹配等
- 缺陷检测、尺寸测量等工业应用

#### 📡 **通信模块**
- 基于 FluentModbus 的 PLC 通信
- 各种工业协议支持（Modbus、OPC等）
- 设备连接与数据交互

#### 🎮 **控制模块**
- 运动控制卡驱动（步进、伺服等）
- IO 卡驱动
- 实时控制信号交互

**设计特点**：
- 🔌 **硬件抽象**：通过接口隐藏硬件细节
- 🔌 **易于扩展**：新硬件驱动开发相对独立
- 🔌 **故障隔离**：硬件驱动异常不影响其他模块

---

### 5️⃣ **Services (04 BaiHua.Software.Services)** - 应用服务层

**职责**：存放与具体硬件无关的系统服务

**主要功能**：
- 🚨 **报警服务**（AlarmService）：报警规则、发送通知
- 📋 **配方服务**（RecipeService）：配方管理、参数设置
- 👤 **用户权限服务**（AuthService）：登录、权限控制
- ⚙️ **系统配置服务**（ConfigService）：参数管理、配置持久化
- 📊 **数据统计服务**（StatisticsService）：生产统计、数据分析

**设计特点**：
- ✅ **与硬件解耦**：业务逻辑与硬件驱动独立
- ✅ **可复用**：同一服务可被多个工站使用
- ✅ **易于测试**：无硬件依赖，便于单元测试

---

### 6️⃣ **BLL (05 BaiHua.Software.BLL)** - 业务逻辑层

**职责**：上位机的**核心大脑**，实现工业流程控制逻辑

**主要功能**：

#### 🏗️ **工艺流程控制**
- 多工站串联控制
- 流程参数下达
- 进度跟踪与反馈

#### 🔄 **工站状态机轮询**
- 周期性状态轮询
- 状态转移逻辑
- 异常状态处理

#### 👁️ **视觉算法逻辑**
- 缺陷检测算法编排
- 尺寸测量逻辑
- 结果判定与反馈

#### 📡 **硬件交互编排**
- 组合调用 HAL 驱动
- 设备通信协调
- 实时数据采集

**调用关系**：
```csharp
// BLL 整合上下游模块
public class WorkstationBLL
{
    private IHALDriver _hal;           // 硬件抽象层
    private IAlarmService _alarm;      // 应用服务层
    private IConfigService _config;    // 应用服务层
    
    public void RunProcess()
    {
        // 1. 从 Services 获取配置
        var config = _config.GetRecipe();
        
        // 2. 调用 HAL 执行硬件操作
        _hal.MoveRobot(config.Position);
        
        // 3. 视觉检测
        var result = _hal.Vision.Detect();
        
        // 4. 结果反馈到报警服务
        if (!result.IsOK)
            _alarm.RaiseAlarm("Defect detected");
    }
}
```

**特点**：
- 🧠 **业务复杂度集中**：流程控制逻辑最复杂
- 🧠 **粘合层角色**：整合各个模块能力
- 🧠 **易于变更**：工艺变更修改此层即可

---

### 7️⃣ **UI (100 BaiHua.Software.UI)** - 用户界面层

**职责**：提供人机交互界面，基于 Prism 框架实现模块化 UI

**技术栈**：
- 🎨 **WPF**：微软原生 UI 框架，支持深度定制
- 🔷 **Prism 9.0**：业界成熟的模块化 MVVM 框架
- 🔌 **DryIOC**：轻量级依赖注入容器
- 📦 **自定义模块系统**：完整的模块生命周期管理

**项目结构**：
```
UI/
├── Views/                      # 共享视图
│   ├── MainWindow.xaml        # 应用 Shell（模块容器）
│   └── ...
├── ViewModels/                 # 共享视图模型
│   ├── MainWindowViewModel.cs # 主窗口模型
│   └── ...
├── App.xaml                    # Prism 应用入口
├── App.xaml.cs                 # Prism 容器注册与模块目录配置
└── docs/                       # 文档
```

**架构层次**：
```
MainWindow (Shell)
    ↓ MainWindowViewModel
┌─────────────────────────────────────┐
│  Prism Region（ContentRegion）      │
│  └─ 根据导航请求切换模块视图        │
└─────────────────────────────────────┘

模块在 `BaiHua.Software.Modules` 中定义，通过 Prism 导航注册到区域；模块 `ViewModel` 再调用 `BLL/Services` 获取真实业务数据
```

**MVVM 数据流**（Prism 风格）：
```
User Interaction (Click, Input)
        ↓
    View (XAML)
        ↓
ViewModel (Prism.BindableBase + DelegateCommand)
        ↓
BLL/Services (业务逻辑)
        ↓
Result ← Data Binding ← ViewModel ← View
        (更新 UI)
```

**主要职责**：
- 📊 **数据展示**：模块化展示各类业务数据
- 🎮 **用户操作**：通过模块接收用户交互
- 🔔 **实时反馈**：基于数据绑定自动更新
- ⚙️ **模块管理**：加载、卸载、区域导航模块

**特点**：
- ✅ **模块化**：功能独立为模块，代码结构清晰
- ✅ **可组合**：支持多模块同时展示
- ✅ **易于维护**：每个模块独立维护
- ✅ **高度解耦**：UI 只依赖接口，不依赖实现
- ✅ **易于扩展**：新功能直接新增模块
